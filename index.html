5. Database Utama Online (Multi-Device Cloud Sync)

Hubungkan ke Google Sheets (Apps Script) atau Firebase agar data dapat diakses di semua perangkat

Hanya Lokal Perangkat Ini
Panduan Setup Database Online Gratis dengan Google Sheets (2 Menit)

1. Buka Google Drive → buat Google Spreadsheet baru.

2. Klik menu Ekstensi (Extensions) → Apps Script, hapus kode lama lalu tempel kode di bawah ini:

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var raw = sheet.getRange('A1').getValue();
  return ContentService.createTextOutput(raw || '{}').setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var body = e.postData.contents;
  sheet.getRange('A1').setValue(body);
  sheet.getRange('A2').setValue('Update Terakhir: ' + new Date().toLocaleString('id-ID'));
  return ContentService.createTextOutput(JSON.stringify({ ok: true })).setMimeType(ContentService.MimeType.JSON);
}

3. Klik Terapkan (Deploy) → Deployment baru → Jenis: Aplikasi web → Yang memiliki akses: Siapa saja (Anyone) → Salin URL Aplikasi Web ke kolom di atas.

6. Backup 1-Klik, Restore & Pemeliharaan Data
